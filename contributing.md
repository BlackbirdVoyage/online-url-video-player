## 💡 What It Does

**Online URL Video Player** is a browser-based and desktop application that plays video content directly from any HTTP, HTTPS, or streaming URL. No downloading required — just paste the link and press play.

It supports the full spectrum of video streaming protocols, from simple MP4 files to complex adaptive bitrate streams (HLS, DASH). It handles the technical complexity behind a clean, minimal interface.

### Supported Protocols

| Protocol | Extension | Use Case |
|----------|-----------|----------|
| 🎬 **Progressive** | MP4, WebM, MKV | Direct video files |
| 📡 **HLS** | M3U8 | Apple adaptive streaming |
| 📺 **DASH** | MPD | MPEG adaptive streaming |
| 🎞️ **HDS** | F4M | Adobe streaming |
| 🔴 **RTMP** | RTMP | Live streaming |
| 📻 **RTSP** | RTSP | IP cameras |
| 🌐 **WebRTC** | - | Real-time comms |
| 📼 **Magnet/Torrent** | - | P2P streams |

## 🛠️ Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| ❌ Video won't play | Bad URL | Verify link |
| ❌ Black screen | Codec missing | Install FFmpeg |
| ❌ No audio | Track selection | Choose audio track |
| ❌ Buffering | Slow network | Lower quality |
| ❌ CORS error | Server policy | Enable proxy |

| ❌ Chromecast fails | Network | Same Wi-Fi |
